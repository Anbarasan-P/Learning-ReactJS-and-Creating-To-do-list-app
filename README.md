# 📝 To-Do List App

A simple and responsive **To-Do List** application built using **ReactJS**, with temporary data persistence using **JSON Server**. Users can add, delete, and mark tasks as completed.

---

## 🚀 Features

- ✅ Add new tasks  
- ❌ Delete tasks  
- ✔️ Mark tasks as complete/incomplete  
- 🔄 Persist data using JSON Server (temporary backend)

---

## 🛠 Tech Stack

- ⚛️ ReactJS  
- 📦 JSON Server  
- 💅 CSS

---

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/Anbarasan-P/Learning-ReactJS-and-Creating-To-do-list-app.git
cd Learning-ReactJS-and-Creating-To-do-list-app

# Install dependencies
npm install

# Start JSON Server
npx json-server --watch db.json --port 3500

# Start React app
npm start

```
